# src/ 前端核心模块说明

本文件夹是项目的 React 前端核心代码，负责用户交互、图片上传与中药识别结果展示。

---

## 📁 文件清单与功能说明

### 1. 主业务文件
- **`App.js`**
  - 项目主组件，实现核心交互逻辑
  - 功能：图片上传、调用后端接口、展示识别结果与置信度、药材百科信息加载

- **`App.css`**
  - 主组件的专属样式文件
  - 控制页面布局、上传按钮、图片预览、结果卡片等样式

- **`index.js`**
  - React 项目入口文件
  - 负责渲染 `App` 根组件到页面 DOM 节点，是项目的启动入口

- **`index.css`**
  - 全局样式文件
  - 设置页面默认字体、边距、背景色等基础样式

---

### 2. 资源与配置文件
- **`logo.svg`**
  - 项目的 Logo 图标文件
  - 用于页面头部展示，提升项目辨识度

- **`reportWebVitals.js`**
  - React 自带的性能监控工具
  - 用于收集页面性能数据（如加载速度、交互响应时间等）

- **`setupTests.js`**
  - 测试环境初始化配置文件
  - 用于配置 Jest 测试工具，为组件单元测试提供支持

- **`App.test.js`**
  - `App` 组件的单元测试文件
  - 用于验证组件的渲染与交互逻辑是否正常工作
